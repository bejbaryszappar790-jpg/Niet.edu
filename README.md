# Niet.edu 🎓

**Niet.edu** — это современная образовательная мобильная платформа, объединяющая преподавателей и студентов. Приложение предоставляет удобный интерфейс для создания курсов, просмотра видеоуроков и отслеживания прогресса обучения.

## 🌟 Основные возможности

### 👨‍🎓 Для Студентов
* **Запись на курсы**: Удобный поиск и добавление курсов в свой профиль.
* **Просмотр уроков**: Встроенный кастомный видеоплеер для просмотра учебных материалов.
* **Отслеживание прогресса**: Сохранение прогресса просмотра видео и пройденного материала.
* **Личный кабинет**: Управление профилем и просмотр своих достижений.

### 👨‍🏫 Для Учителей
* **Панель управления**: Специальный интерфейс для управления образовательным процессом.
* **Создание курсов**: Добавление новых обучающих курсов и модулей.
* **Загрузка видео**: Удобная публикация видеоуроков.
* **Статистика**: Просмотр списка студентов и их успеваемости по курсам.

### 🔒 Безопасность и Авторизация
* Раздельная система ролей (Учитель / Ученик) еще на этапе регистрации.
* Надежная аутентификация с использованием JWT (Access и Refresh токены).
* Безопасное хранение сессий на устройстве с помощью `flutter_secure_storage`.
* Жесткий роутинг (Guard) — защита от несанкционированного доступа к разделам приложения.

## 🛠 Технологический стек

### Frontend (Мобильное приложение)
* **Фреймворк:** [Flutter](https://flutter.dev/)
* **Архитектура:** Clean Architecture
* **State Management:** [BLoC](https://bloclibrary.dev/) (Business Logic Component)
* **Навигация:** [GoRouter](https://pub.dev/packages/go_router)
* **Сетевые запросы:** [Dio](https://pub.dev/packages/dio) (с Interceptors для авто-обновления токенов)
* **Хранилище:** [Flutter Secure Storage](https://pub.dev/packages/flutter_secure_storage) / SharedPreferences
* **Медиа:** `video_player` / `youtube_player_flutter` (кастомный UI плеера)

### Backend (API)
* **Фреймворк:** [FastAPI](https://fastapi.tiangolo.com/) (Python)
* **ORM:** SQLAlchemy
* **Миграции БД:** Alembic
* **Аутентификация:** JWT-токены
* **Схемы данных:** Pydantic

🚀 Запуск проекта (Локально)
1. Запуск Backend-сервера
Убедитесь, что у вас установлен Python 3.9+ и зависимости из requirement.txt.

bash


cd app
# Активация виртуального окружения (если используется)
uvicorn main:app --reload
API будет доступно по адресу: http://127.0.0.1:8000

2. Запуск Flutter-приложения
Убедитесь, что у вас установлен Flutter SDK.

bash


# Получение зависимостей
flutter pub get
# Генерация кода (при необходимости)
flutter pub run build_runner build
# Запуск на iOS/Android симуляторе с указанием IP бэкенда
# Замените IP на адрес вашего компьютера в локальной сети, если запускаете на физическом Android-устройстве
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8000
